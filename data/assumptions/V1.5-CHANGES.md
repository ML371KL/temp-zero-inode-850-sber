Версия записана: 29.10.2026; дата книги (`meta.date`) — 28.10.2026: день цены и оценки, на которых книга собрана (как у
1.4: книга собрана в ночь на 29.10.2026, последняя основная сессия — 28.10.2026; кривые миров прежние — запись семейства
magnit-850oa book-1.6, кривая 18.09.2026). Тег: `book-1.5` (ставится на коммит выпуска книги). Якорь (3К26), факты
(`data/facts/` — без изменений), миры, цена (298,70 / 299,00 ₽) — те же, что у книги 1.4. Основание — разбор отчёта
МСФО за 9 месяцев 2026 года (28.10.2026): «прочее» ОПУ 3К26 −157,5 млрд ₽ против ≈ −31 по профилю книги. Решения —
`docs/DECISIONS.md`, часть 14; лист — `evidence/misc`.

## 2. Лист «прочего» (`evidence/misc/misc_book.py`)

«Прочее» (М§4.7) — остаток ОПУ до налога без ЧПД, резервов по долговым ФА, ЧКД, страхования (выручка + расходы на
услуги), непрофильного результата и расходов. Лист раскладывает его по строкам отчёта за 11 кварталов 2024К1–2026К3
(малый вход — `ifrs_quarterly.csv` этапа 1 на якоре 3К26; кредитная переоценка кредитов по СС — примечания о кредитах
МСФО 2024–9М26) и переводит кварталы в цены якоря (ИПЦ Банка России, помесячная цепочка; 1К24 × 1,209 … 2К26 × 1,015).

## 5. Как воспроизвести

```

python -B data/assumptions/evidence/misc/misc_book.py            # лист «прочего»; код 1 — книга расходится с правилами
python -B data/assumptions/build_assumptions.py [--check]
python -B -m model.book_results && python -B ops/tools/render_numbers.py && python -B -m tests.test_control_model --write
python -B data/assumptions/evidence/governance/governance_channels.py   # вход median_rub — медиана книги 1.5
git show book-1.4:data/assumptions/assumptions.json > var/b15/book-1.4.json
python -B ops/tools/walk_book.py --start var/b15/book-1.4.json --end data/assumptions/assumptions.json \
       --steps var/b15/walk-1.5-steps.yaml --median
```
