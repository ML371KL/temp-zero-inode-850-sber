# Доказательные листы книги допущений

Каждое число книги, которое не взято прямо из документа, посчитано здесь — воспроизводимо, без сети, из корня
репозитория (`python -B data/assumptions/evidence/<область>/<скрипт>.py`). Листы этапа 1 перенесены с минимальной
правкой: меняются только корни путей. Входы лежат в `<область>/inputs/` под теми же относительными путями, что в папке
передачи (`inputs/stage1/ifrs/ifrs_quarterly.csv` …): большие листы сокращены до строк, которые читают скрипты области
(`extract_inputs.py`, опись — `inputs/SOURCES.json`: sha256 полного листа и малого входа). Первичка (PDF) в репозиторий
не кладётся — только ссылкой, страницей и sha256 внутри листов. Ответы брокерского API не кладутся вовсе — ни файлом
ответа, ни таблицей, ни выпиской его полей. Дивиденды — публичные факты: лист β берёт лист решений годовых собраний
акционеров (`beta/inputs/stage1/market/shares_dividends/dividends_public.csv`: год прибыли, дивиденд на акцию, дата
отсечки — с источником каждого года: страница «Дивиденды» на сайте банка и новость о решении); лист `dividends` берёт
объявленный дивиденд из листа с источниками МСФО (`pool_check.csv`). Выходы — `<область>/out/`.

Проверки: `tests/test_book_evidence.py` запускает каждый лист в копии во временном каталоге и сверяет выходы с
лежащими и с книгой (скрипты `*_book.py`, `compare()` — код выхода 1 при расхождении с шаблоном); тесты с маркером
`archive` (нужна `BANK_HANDOFF_DIR`) сверяют малые входы с листами этапа 1 и выходы перенесённых листов — с выходами
этапа 1 (совпадают: ЧПД — всё, кроме описи входов и доли ликвидных, которая с книги 1.2 считается без акций и фондов;
капитал — байт в байт; β — все числа: отличаются подпись источника дивидендов и строки сверки экс-дат — без даты из
брокерского календаря). Листы правил (центры долей, история спредов,
неподвижная точка дисконта) — код выхода 1 при расхождении книги с правилом.

python data/assumptions/evidence/extract_inputs.py [область …] [--check]`.
