п. 5; MODEL §4.11). Запуск из корня репозитория по порядку:

ряды `gap_n20_quarterly.csv`, `n11_bridge_quarterly.csv`, `bv_to_capital_quarterly.csv`, `bank_monthly.csv`,
`fvoci_*.csv`, `forward_check.csv`; `gap_additive_out.json`; сверка с книгой `capital_book_out.json`).
