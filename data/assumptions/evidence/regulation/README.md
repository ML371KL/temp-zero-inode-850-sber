# regulation — регуляторные сценарии капитала (A-K1b, A-K3b)

Полы и требования по годам из траекторий книги (`capital.reg_scenarios`, `capital.minimum`, `capital.mgmt_buffer`,
`dividends.policy.threshold`) против регуляторного графика этапа 1 (`inputs/stage1/regulation/schedule.yaml`: 220-И
пп. 2.2, 3.2, 3.4, 3.5; ОФС ЦБ 05.2026 с. 63; доклад ЦБ о новой методике СЗКО 22.05.2025; отчёт 20.02.2026; страница
АЦН ЦБ). Запуск из корня репозитория: `python -B data/assumptions/evidence/regulation/floors.py` →
`out/floors_out.json` (выход 1 — книга расходится с графиком).
