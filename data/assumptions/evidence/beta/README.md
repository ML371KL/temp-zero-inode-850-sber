# beta — β капитала (A-V1)

Перенос листа этапа 1 `market/beta` (правило семейства A-V1 850oa: недельная полная доходность — цена плюс валовой
дивиденд в экс-дату — против индекса полной доходности MCFTR, окна 2 / 3 / 5 лет, МНК, Ньюи — Уэст; у банка — β
капитала без разрычаживания). Запуск из корня репозитория: `python -B data/assumptions/evidence/beta/beta_sber.py` →
`out/beta_out.txt`, `out/beta_results.csv`, `out/beta_summary.json` (числа — как у листа этапа 1). Входы — цены
MOEX ISS TQBR и индексов (`inputs/stage1/market/beta/inputs/`) и лист решений годовых собраний акционеров о
дивидендах `inputs/stage1/market/shares_dividends/dividends_public.csv`: год прибыли, дивиденд на обыкновенную и на
привилегированную акцию, дата отсечки, дата решения — с публичным источником каждого года (страница «Дивиденды» на
сайте банка и новость о решении собрания: издание, дата, заголовок, адрес). Тот же лист читает сборщик фактов
(`data/facts/dividends.json`); экс-даты лист β считает сам — от отсечки по торговому календарю бумаги, и сверяет
каждую гэпом цены. Ответов брокерского API и выписок из них в репозитории нет (`evidence/README.md`).
