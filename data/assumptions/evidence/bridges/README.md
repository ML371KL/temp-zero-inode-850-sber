# bridges — мосты базисов и строки ОПУ

Перенос сверок критика этапа 1 (`cor_bridge.py`, `ras_ifrs_bridge.py`, `misc_hist.py`) в один лист плюс числа строк
ОПУ, на которых стоят ключи `fees`, `opex`, `noncore`, `other`, `tax`, `pnl`, `nii.dia_rate`. Базисы не смешиваются:
МСФО группы, упр. метрики банка, РСБУ банка — отдельными рядами; перевод — только мостами. Запуск из корня
репозитория: `python -B data/assumptions/evidence/bridges/bridges.py` → `out/bridges_out.json` (мост ЧПМ читает выход
листа ЧПД `../nii/out/history_fit.csv`).

## Результаты

* **Мост CoR** (CoR движка = −резервы по долговым ФА / средние валовые кредиты АС × 365/d; MODEL §4.6): движок − упр. =
  **+0,17 ± 0,16 п.п.** (1К24–2К26, n 10; аддитивный); отношение 1,14; 2К26 — +0,43, 2023 — от −0,25 до +0,22.
  → `regimes.cor_basis: mgmt`, перевод в ядре `to_engine_cor`; `checks.bridge_drift_pp.cor` 0,004 ≈ 2,5σ.
* **Мост ЧПМ**: упр. − движок = **+0,41 п.п.** (1К24–2К26, n 10) на процентных активах листа — с акциями и фондами в
  бумагах. Ядро переводит A-N2 в движок фактом `data/facts/bridge_mgmt_ifrs.json` — **−0,384 п.п.** (σ 0,02 п.п.; активы
  без акций и фондов, как у книг ядра); 0,41 — справочно, базы не смешиваются.
* **Сезонный мост прибыли РСБУ банка → ЧП акционерам МСФО** (нау-каст): 1К **1,058**, 2К **1,015**, 3К **1,003**, 4К
  **0,962**; за год 1,013 / 1,012 / 1,008 (2023–2025).
* **«Прочее» ОПУ** (PBT − ЧПД − резервы − ЧКД − страхование − непрофильный − расходы; страхование = выручка + расходы

* **Неконтролирующие доли**: −0,09 % ЧП 2025 → `pnl.nci_share` 0.
* **Взносы АСВ**: 87,3 × 365/181 / 33 972 = **0,52 %** → `nii.dia_rate` 0,0052.
