# dividends — формула пула и DPS, акции якоря (A-D*)

Проверка политики 2023 (dividend_policy_2023.pdf, sha256 f486aa17…; п. 1.6, 2.2–2.3) на истории: `пул = 0,5 × (ЧП
акционерам МСФО − купон AT1 × (1 − τ))`, `DPS = пул × 1000 / размещённые акции обеих категорий` в точной десятичной
арифметике (MODEL §5.2, прил. C). Запуск из корня репозитория:
`python -B data/assumptions/evidence/dividends/dps_history.py` → `out/dps_history_out.json`. Входы — лист этапа 1
`pool_check.csv` (ЧП акционерам, купон AT1, ставка налога и объявленный дивиденд на акцию по годам — с документом и
страницей МСФО в столбце `source`) и число размещённых акций (MOEX ISS, ISSUESIZE). Объявленный дивиденд на акцию —
решения годовых собраний 2024–2026 годов (33,30 / 34,84 / 37,64 ₽); лист сверяет его с объявленной суммой отчётности:
DPS × размещённые акции = 752,1 / 786,9 / 850,2 млрд ₽ (столбцы `declared_x_issued_bn` и `declared_total_bn_ifrs`).
Таблицы выплат из ответов брокерского API в репозиторий не кладутся (`evidence/README.md`).
