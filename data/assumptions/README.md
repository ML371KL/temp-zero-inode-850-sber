# Книга допущений Сбербанка

Единственный экземпляр книги допущений модели: ядро читает только машинную книгу `assumptions.yaml`
(`model/book.py`, закрытая схема `model/book_schema.py`, ключи — `docs/MODEL.md`, приложение A). Книгу меняет только
её новая версия; решает о ней владелец или ведущий. Версии помечаются тегами git `book-<версия>`
(`git show book-1.0:data/assumptions/assumptions.yaml`).

## Что здесь

| Файл | Что |
|---|---|
| `ASSUMPTIONS-BOOK.md` | текст книги: суждения, числа, оси, класс надёжности, обоснования с источниками, чем могут ошибаться (идентификаторы A-xx — те же, что в комментариях шаблона) |
| `assumptions_template.yaml` | шаблон машинной книги — все ключи прил. A, кроме `worlds.<W>.*` и `worlds_bank.*`; **правят его** |
| `assumptions.draft.yaml` | черновик книги 1.0 (схема и числа решений 01.10.2026) — основа шаблона, справочно |
| `V<версия>-CHANGES.md` | журнал версии: что изменилось по ключам, почему (решения), как воспроизвести (`V1.1-CHANGES.md`, `V1.2-CHANGES.md`, `V1.3-CHANGES.md`) |
| `build_assumptions.py` | сборщик: шаблон + миры семейства + банковская надстройка + хэши → `assumptions.yaml` и `assumptions.json`; `--check` — сборка воспроизводит файлы; функция `build()` |
| `assumptions.yaml`, `assumptions.json` | машинная книга — выход сборщика; руками не правится |
| `worlds_source.json`, `worlds_source.csv` | общая запись миров семейства (850oa, книга 1.6; `asof` 21.09.2026, кривая 18.09.2026) — **побайтово** (sha256 `worlds_source.json` 7296567d…, CRLF; `.gitattributes`: `worlds_source.* -text`) |
| `worlds_inputs.yaml`, `worlds_recipe.py`, `WORLDS-RECIPE.md` | рецепт миров книги-источника — обезличенные копии, как у «Ленты» (без тикера, адреса выпуска и сумм книги-источника; функционально те же, переводы строк — LF); `python -B data/assumptions/worlds_recipe.py --check` воспроизводит запись |
| `worlds_bank.json` | банковская надстройка миров (рост кредитов по сегментам, средств, номинального ВВП; 2026–2029) — собирает `evidence/worlds_bank/build_overlay.py`, хэш — в `worlds.overlay.sha256` |
| `evidence/` | воспроизводимые расчёты книги по областям (`evidence/README.md`) |
| `results.json`, `run_output.txt` | таблицы книги — выпуск ядра (`python -B -m model.book_results`), коммитит интеграция |
| `gate_explanations.yaml` | объяснения сработавших гейтов (MODEL §14.2) — эксплуатация, правится без новой версии книги; текст печатает витрина — словами для владельца |
| `release_notes.yaml` | записки о задуманных скачках заголовка (MODEL §14.4) — эксплуатация |

## Порядок новой версии книги

Из корня репозитория, Python 3.12 (stdlib + PyYAML):

1. Правка `assumptions_template.yaml` и текста `ASSUMPTIONS-BOOK.md`; новые расчёты — листом в `evidence/<область>/`
   (входы — `inputs/`, первичка — ссылкой и sha256; малые входы из листов этапа 1 — `evidence/extract_inputs.py`).
   Комментарий шаблона у ключа, на котором стоит ось полосы, — источник суждения на витрине: одна метка с текстом
   после двоеточия, не длиннее 80 знаков, словами для владельца (без имён листов и ключей, даты — с годом, версии — с
   именем); у оси — поле `unit` (единица печати).
   В шаблоне поднять `meta.version`. `meta.date` — дата книги: день цены, кривых и оценки, на которых она собрана
   (её печатает выпуск: «книга от …»); она меняется, когда книга переходит на новую цену и кривые, а не с каждой
   версией (у 1.0–1.3 — 30.09.2026). День записи версии — столбец «Записана» журнала ниже. При перезаякоривании —
   `meta.facts_date`, `anchor_period`, `first_period` вместе с фактами `data/facts/`.
2. Миры пересобираются только вместе с книгой-источником семейства: новая запись `worlds_source.json` (+ `.csv`) —
   побайтово, рецепт `worlds_recipe.py --check` обязан её воспроизводить; в шаблоне — `worlds.source.{sha256,
   record_asof, curve_date}` и `meta.curve_as_of`. Надстройка — `python -B data/assumptions/evidence/worlds_bank/build_overlay.py`
   (после правки черновика — `--sync` из `$BANK_HANDOFF_DIR`).
3. `python -B data/assumptions/build_assumptions.py` — пишет `assumptions.yaml` и `assumptions.json`.
4. `python -B -m model.book_results --fast` — проба: книга грузится ядром (закрытая схема, `null` в читаемом пути —
   отказ) и считается; затем полный `python -B -m model.book_results` (`results.json`, `run_output.txt`) и
   `python -B ops/tools/render_numbers.py` — числа ядра в текст книги по меткам (раздел 0 `ASSUMPTIONS-BOOK.md`).
5. Прогулка книги между версиями (`ops/tools/walk_book.py`) — разница выводов создана допущениями, а не кодом; журнал
   версии — `V<версия>-CHANGES.md` рядом. Ключи, заданные правилом, пересчитываются: центры `nii.sigma0_split` и
   `nii.phi_split` — листами `evidence/nii/sigma0_split.py` и `phi_split.py` (стационар на структуре якоря — до
   прогона; меняются с якорем, спредами книг, целями A-N2, A-N3 и полами спреда); концы осей обеих долей — теми же
   листами: оси лежат в области, где гейт `lt_spread_floor` проходит во всех мирах (лист отказывает, если ось книги
   из неё выходит); дисконт за управление — неподвижная
   точка на медиане выпуска (`evidence/governance`, вход `fixed_point.median_rub` — после прогона; ключ меняется, если
   отстоит от точки больше чем на половину шага). Тесты книги сверяют листы с `results.json` той же версии.
6. Проверки: `pytest --basetemp=var/pytest-book tests/test_book_*.py` (шаблон, сборка, прил. A, миры бит в бит,
   надстройка, листы `evidence/`, печатаемые строки, тест знака объёмных эффектов и цепочка отчётов «без новостей» на
   ядре), затем полный `pytest`. Сработавшие гейты — записи в `gate_explanations.yaml` (текст — для владельца).
7. Коммит версии и тег `book-<версия>` на нём (`git tag book-1.3`); тег не переносится — ошибка исправляется
   следующей версией.
