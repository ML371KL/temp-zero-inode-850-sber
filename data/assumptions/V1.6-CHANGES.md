## 4. Как воспроизвести

```
python -B data/assumptions/worlds_recipe.py --check                         # запись 1.7: 63 строки
python -B data/assumptions/evidence/worlds_bank/build_overlay.py --check   # надстройка 8611f015…
python -B data/assumptions/evidence/nii/h_path_spreads.py                  # ключи 2028–2030 на пути мира H
python -B data/assumptions/evidence/nii/near_spreads.py                    # ближние ключи (после h_path_spreads)
python -B data/assumptions/evidence/nii/sigma0_split.py && python -B data/assumptions/evidence/nii/phi_split.py
python -B data/assumptions/build_assumptions.py [--check] && python -B ops/tools/refresh_worlds.py --check
python -B -m model.book_results && python -B ops/tools/render_numbers.py && python -B -m tests.test_control_model --write
python -B data/assumptions/evidence/governance/governance_channels.py      # вход median_rub — медиана книги 1.6
python -B ops/tools/walk_book.py --start var/walk-1.6/start.yaml --end data/assumptions/assumptions.yaml \
       --steps var/walk-1.6/steps.json --median --draws 500
```

Шаги прогулки (файл в `var/`, вне репозитория; значения шагов «запись» — блоки миров записи 1.7 без согласования ИПЦ H и
зарплат, собранные рецептом из входов первого захода канона; шаг «ключи 2028–2030» ставит ключи книги 1.6):
версия 1.6 → миры ставок (ЦБ 23.10.2026): запись 1.7, дата кривых, ближние ключи → средний ИПЦ мира H по концам периода →
зарплаты текущего полугодия по факту → уровень кривой в терминале N/H правилом → надстройка 1.7 → дисконт за управление
0,45 % → ключи спредов 2028–2030 на пути мира H.
