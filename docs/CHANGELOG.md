нау-каст ЧПМ (к цене не подключён).

  новые. Запись T−30 за 3К26 по новому профилю — 6,75 % вместо 6,78 % (факт 6,65 %). В `nowcast.json` у ЧПМ —
  `profile_rule`. Версия нау-каста — `nowcast-3` (записи журнала до неё остаются с `nowcast-2`).
- **Дозор РСБУ** `indicators/release_watch.py`: поток одного вида принимается тождеством в допуске `identity_accept`
  0,15 млрд ₽ (`sources.yaml`; наибольшая ошибка округления трёх чисел с точностью 0,1); общая проверка тождества —
  прежняя (`identity`, 0,35).
- **Тесты такта:** правило профиля на истории без хранилища, профиль ретро против явной формулы, допуск приёма.

## Правки по внешнему аудиту (06.10.2026)

По независимому аудиту кода `74cb9e8` (восемь замечаний, существенной ошибки числа нет) и решению
владельца «исправить всё сразу» (`docs/DECISIONS.md`, часть 12). **Число книги 1.3 — то же, бит в
бит:** точка 379,40 ₽, медиана 348,60 ₽, полоса 80 % 251,4–456,4 ₽ на цене книги.

- **Капитал:** из базового капитала исключается только неаудированная прибыль, `max(E, 0)`; убыток
  периода уменьшает его сразу (ядро и контрольная модель). Меняется только путь прокси Н20.1 в
  квартале разового убытка клеток кризиса (ниже на 0,25–0,29 п.п.).
- **Книга и проверки:** вероятности, λ и ε — в [0; 1] схемой книги (и концы осей с таким путём; у
  оси-сдвига — значение книги со сдвигом, вероятность таблицы сдвигом не водят);
  инвариант `probabilities` называет отрицательный вес; `dividend_bounds` сравнивает с запасом
  капитала всю выплату года. Пять новых мутаций, все ловятся.
- **Формы ЦБ:** дата «обработана», только когда форма скачана и разобрана; несделанное — очередь
  каждого такта с деградацией, поэтому повтор сбора добирает форму, а тревога не гаснет на втором
  проходе; заглушка с кодом 200 (список без дат, «форма» без конверта SOAP) — отказ с повтором, а
  не версия формы; неразобранная попытка в записи одна; о пересмотре такт сообщает, когда новый
  винтаж лёг в ряды; дата в очереди запрашивается и без упоминания в списке; недельная сверка — по
  записи. Индекс прежнего формата читается как есть.
- **Нау-каст:** месяц по форме 0409102 пересчитывается при пересмотре прошлого нарастающего итога
  (итоги одного момента входят вместе); факт квартала читается по дате; σ_РСБУ(k) меряется на знании
  дня, когда вышел k-й месяц, не раньше открытия квартала (у ЧПМ 0,24 / 0,28 / 0,13 / 0,10 п.п.
  вместо 0,20 / 0,26 / 0,13 / 0,10; у прибыли — та же). σ открытого квартала заморожена журналом и
  не меняется.
- **Хвост полосы:** сообщения гейтов `capital_gap` и `roe_gt_g` называют, в скольких прогонах полосы
  есть клетки с капитальным разрывом, с ROE терминала не выше роста и с отрицательной стоимостью, их
  массу в среднем по всем прогонам и сдвиг низа полосы и медианы при нулевом поле стоимости клетки.
  Контракт выпуска не меняется (текст поля `message`); витрина печатает сообщение и у несработавшего
  гейта — под его коридором, в карточке «Проверки» (прежде сообщения печатались только у сработавших).
- Таблицы книги и сводка сверки с контрольной моделью перевыпущены на коде правок `1390b8c`

  проверки переносится, а не обрезается. Регистрация у сторожа свежести — по-прежнему шаг владельца.
