  источника — внутри утреннего такта, до 3 попыток с паузой (`ops/run.sh`,

  команды (раньше опечатка в `BANK_DATA_REPO_DIR` стирала каталог без `.git`);
  автор коммитов сверяется со списком `.github/commit-emails.allow`; git без хуков
  и монитора файлов клона; откат выпуска с незавершённой сверкой не отменяется
  пересборкой.
- **Гигиена:** в тесте нет личных слов и их хэшей — список вне репозитория, сверка
  перед push (метка `archive`); правила без списка — путь к файлу ключа в `.ssh`,

- **Сторожа меток** читают метки и через имена-псевдонимы модуля
  (`tact = pytest.mark.tact`); в такте обязаны быть тесты потока перезаякоривания.
- **Документы:** процедура первого push одним свежим корневым коммитом
  (`ops/README.md` §12, `docs/DECISIONS.md` часть 5); проба доставки тревоги через
  юнит; установка — пакеты до пробы источников, сверка через юнит пересборки;
  перезаякоривание и эталоны журнала в справочнике (`docs/MANUAL.md` §10.4, §10.8);
  рост ветки данных (`ops/README.md` §9); набор тестов сервера — `TACT_TESTS`, а не
